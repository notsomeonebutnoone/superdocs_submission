# Assigned clip: per-message revert

## Deliverable

A private screen recording, between fifteen and thirty seconds, demonstrating and selling per-message revert. It must use the candidate's real voice and must not be posted publicly. The repository contains the recording plan only because a human voice and authenticated product session cannot be generated honestly here.

## Setup

- Use a synthetic proposal with a short executive summary.
- Create a useful edit, then issue a deliberately bad instruction that makes the summary too casual.
- Keep the relevant chat message and changed document area visible together.
- Hide account details, keys, browser bookmarks, and notifications.
- Record a clean crop at readable zoom.

## Spoken script

> This edit went too far. I do not want to undo the good work before it, or rebuild the document from scratch. I can revert this message alone. The document returns to the version before that instruction, while the earlier edits stay in place. That is the difference between experimenting with AI and being afraid of the next prompt.

The spoken and visible demonstration should contain no counters, prices, percentages, list numbering, or fabricated performance claims.

## Shot sequence

- Begin on the proposal after the intentionally bad change.
- Point to the instruction that caused it.
- Use that message's revert control.
- Hold on the restored document and the earlier retained edit.

## Acceptance checklist

- Duration is within the assigned range.
- Candidate voice is audible and natural.
- One message is reverted; this is not browser undo or whole-document reset.
- Earlier accepted work remains visible.
- No real customer data or secrets appear.
- No numbers or counts appear in the clip content.
- File is uploaded only to the submission destination, not a public channel.
