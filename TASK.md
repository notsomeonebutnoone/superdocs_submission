# How to work this round

This file is the operating manual for the SuperDocs GTM / Growth Engineer submission in this repository.

## Role of this repo

Private submission repo for the growth task. Name pattern: `doctask-<name>`. SuperDocs is not in the name on purpose — the machine is ours to keep.

Invite **github.com/o-kadam** as collaborator when publishing. Drop the repo link into the submission form as well.

## What must ship (floors — none optional)

| ID | Deliverable | Folder |
|----|-------------|--------|
| T1 | Growth machine (audience + runnable system ×2 + piece + measurement) | `task-1-growth-machine/` |
| T2a | Build in public — five posts over ~ten days | `task-2-builds/build-in-public/` |
| T2b | Agent-ecosystem map with extension mechanics | `task-2-builds/agent-ecosystem-map/` |
| T3 | ~10 use cases with real companies + conversation openers | `task-3-use-cases/` |
| Clip | 15–30s screen recording: **Per-message revert** | `clip-task/` |
| T4 | Demo video (~3 min) + one-page write-up | `task-4-demo-and-writeup/` |

Open-list extras and inventions are voluntary. Depth beats breadth.

## Bright lines (never cross)

- **No outreach to real people or real companies** while this round runs. Machine produces drafts only; nothing is sent.
- Real **companies** may appear in research. Real **people** (private individuals) may not be named.
- Claims never outrun the product. Spec ceiling = **docs + what the app does today**, not marketing aspirations.
- No API keys in the repo, screenshots, or demo video.
- No SuperDocs clone. Build *on* SuperDocs or *around* reaching people who need it.
- Clip of product features is **not** for public posting. Own builds may be posted with affiliation disclosed.

## Working methods

1. Log assumptions and cuts in `PROGRESS.md` as you go.
2. Checkpoint long runs; save immediately.
3. Prefer a small machine that runs twice over a grand deck that does not run.
4. Verify with a fresh eye (different session / checklist) before calling something done.
5. Use AI heavily; disclose direction in the form. Demo video, write-up voice, and live conversation are human.
